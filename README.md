## Como aplico esses conhecimentos

Nos projetos desenvolvidos, utilizo uma estrutura semelhante a:

```text
Cliente ou Postman
        ↓
Controller
        ↓
Service
        ↓
Repository
        ↓
JPA / Hibernate
        ↓
Banco de dados
```

Os controllers disponibilizam os endpoints HTTP, a camada de serviço concentra as regras de negócio e os repositories realizam o acesso aos dados.

Os DTOs controlam quais informações entram e saem da API, enquanto o Bean Validation, o tratamento de exceções e os códigos de status HTTP tornam as respostas mais consistentes.

Quando necessário, os endpoints são protegidos com Spring Security, OAuth2 e tokens JWT.
